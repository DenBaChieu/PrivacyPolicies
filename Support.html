Common Issues

If you encounter any issues with the app, please check the following:

  • Ensure you have the latest version of the app installed.
  • Restart the app to resolve minor glitches.
  • Check your device's internet connection if the app requires it.

Issue: The text size is too small/ too large and the text size setting is not enough to fix it
Solution: You can change the text size in your device's settings. The app text size setting is designed to adjust the text size within a reasonable range, but it may not cover all cases.

Issue: Can't find a specific fault code/ device I need
Solution: Contact us via email with the details of the fault code or device you are looking for. We will do our best to assist you and update the app if necessary.
